🧪 TESTING STEPS
────────────────────────────────────────────────────────────────────────────────

1. VIEW LANDING PAGE
   → Go to http://localhost:3000
   → See hero, 4 features, CTA button
   → Click "START YOUR JOURNEY"

2. VIEW CHAT INTERFACE
   → Redirected to /chat
   → Click Tools button (⚙️) to see colored prompts
   → Wait for AI response with food cards
   → See new food card layout with metadata

3. TEST QUICK PROMPTS
   → Click Tools button in input area
   → 3 pills with icons: Clock, Leaf, Flame
   → Click any pill to send prompt

4. VIEW FOOD CARD DETAILS
   → In AI response, check each card for:
     • Image placeholder
     • Cooking time & servings
     • Difficulty badge
     • Nutrition grid (calories, protein, carbs, fat)
     • Tags
     • Blue "Tại sao lại gợi ý?" box
     • Location button

5. TEST FEEDBACK SYSTEM
   → Look for feedback icons on cards
   → Click to open RecipeFeedbackDialog
   → Rate with stars, add comment
   → Submit feedback

6. TEST ONBOARDING
   → Go to http://localhost:3000/(auth)/onboarding
   → See progress bar & step indicators
   → Select preferences, click Next
   → Check Previous button works

📝 INTERFACE UPDATES
────────────────────────────────────────────────────────────────────────────────
BackendFoodResult now includes:

  image?: string                           (recipe image URL)
  cookingTime?: number                     (minutes)
  difficulty?: "easy"|"medium"|"hard"      (difficulty level)
  servings?: number                        (number of servings)
  calories?: number                        (per serving)
  protein?: number                         (grams)
  carbs?: number                           (grams)
  fat?: number                             (grams)
  tags?: string[]                          (e.g., "vegetarian")
  reason?: string                          (why recommended)

💡 HELPFUL TIPS
────────────────────────────────────────────────────────────────────────────────
• All new components use Tailwind CSS + Material-UI
• Components are fully typed with TypeScript
• Responsive design works on mobile/tablet
• Dark mode is supported
• Colors use HSL format for consistency

• To debug, check console.log messages with "[v0]" prefix
• To modify colors, edit src/app/globals.css
• To update food card layout, edit src/features/chat/components/food-card.tsx
• To modify quick prompts, edit src/features/chat/components/thread/input-area.tsx
